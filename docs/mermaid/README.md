# YGO Deck Lab Mermaid Diagrams

이 폴더의 `.mmd` 파일은 설계서에 들어갈 다이어그램 원본입니다.

사용 방법:

1. Mermaid Live Editor 또는 VSCode Mermaid Preview 확장을 연다.
2. 필요한 `.mmd` 파일 내용을 붙여 넣는다.
3. PNG 또는 SVG로 export한다.
4. 설계서의 해당 placeholder 위치에 이미지를 삽입한다.

파일 목록:

- `01_erd_crowsfeet.mmd`: Crow's Feet ERD
- `02_architecture.mmd`: 프로젝트 아키텍처
- `03_repository_class.mmd`: Repository / Provider / Service UML
- `04_seq_uc01_initialize.mmd`: UC-01 시스템 초기화 및 카드 데이터 연동
- `05_seq_uc02_search_cards.mmd`: UC-02 카드 검색
- `06_seq_uc03_card_detail.mmd`: UC-03 카드 상세 조회
- `07_seq_uc04_deck_validate.mmd`: UC-04 덱 구성 및 금지 제한 검증
- `08_seq_uc05_save_deck.mmd`: UC-05 덱 저장
- `09_seq_uc06_saved_deck_query_delete.mmd`: UC-06 저장된 덱 조회 및 삭제
